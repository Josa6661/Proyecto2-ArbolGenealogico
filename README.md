# Proyecto2-Algoritmos y Estructuras de Datos I

Aplicación en C# usando WPF para la gestión y visualización gráfica de un árbol genealógico y sus relaciones geográficas.

## Estructura del proyecto

- **Assets:** Recursos visuales (imágenes, íconos, mapas).
- **DataStructures:** Implementaciones manuales de estructuras de datos (array, lista enlazada, stack, queue...).
- **MapUI:** Componentes gráficos e interacción en el mapa.
- **Models:** Clases principales de datos.
- **Services:** Lógica de negocio, gestión y manipulación del árbol/grafo.
- **Tests:** Pruebas unitarias para validar cada módulo.
