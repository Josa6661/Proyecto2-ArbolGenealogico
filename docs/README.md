# Documentación del Proyecto - Árbol Genealógico

Esta carpeta contiene la documentación técnica completa del proyecto Árbol Genealógico.

## 📚 Contenido

### [Diagrama de Arquitectura](./Diagrama-Arquitectura.md)
Descripción completa de la arquitectura del sistema, organización en capas, flujos de datos y patrones de diseño utilizados.

**Incluye:**
- Diagrama de arquitectura en capas (Mermaid)
- Descripción detallada de cada capa
- Flujos de datos principales
- Patrones de diseño aplicados
- Tecnologías y librerías utilizadas
- Ventajas de la arquitectura elegida

### [Diagrama de Clases](./Diagrama-Clases.md)
Diagrama UML completo con todas las clases del sistema, sus relaciones, atributos y métodos.

**Incluye:**
- Diagrama UML completo (Mermaid)
- Descripción detallada de cada clase
- Relaciones y multiplicidad
- Principios SOLID aplicados
- Complejidad algorítmica de operaciones
- Diagrama de secuencia para operaciones clave

## 🎯 Uso de la Documentación

### Para Desarrolladores
- Consulta el **Diagrama de Arquitectura** para entender la organización general del proyecto
- Revisa el **Diagrama de Clases** para conocer las clases específicas y sus responsabilidades
- Los diagramas Mermaid se visualizan automáticamente en GitHub

### Para la Wiki de GitHub
Estos archivos están diseñados para ser incluidos directamente en la wiki de GitHub:

1. Ve a la pestaña **Wiki** de tu repositorio
2. Crea nuevas páginas con los nombres correspondientes
3. Copia y pega el contenido de cada archivo .md
4. Los diagramas Mermaid se renderizarán automáticamente

## 📊 Visualización de Diagramas

Los diagramas están escritos en **Mermaid**, que se renderiza automáticamente en:
- GitHub (README, Wiki, Issues, Pull Requests)
- VS Code (con extensión Mermaid)
- GitLab
- Notion
- Obsidian

## 🔄 Actualización

Esta documentación debe actualizarse cuando:
- Se agreguen nuevas clases o estructuras de datos
- Cambie la arquitectura del sistema
- Se implementen nuevos patrones de diseño
- Se agreguen nuevas funcionalidades importantes

## 📝 Convenciones

- Los diagramas usan **colores** para diferenciar capas:
  - 🔵 Azul: Capa de Presentación
  - 🟢 Verde: Lógica de Negocio
  - 🟠 Naranja: Servicios
  - 🟣 Morado: Estructuras de Datos
  - ⚫ Gris: Estructuras Genéricas
  - 🟡 Amarillo: Utilidades
